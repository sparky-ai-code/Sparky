Read & Edit Files

Open any text file, make changes, and see exactly what changed before saving. Works with code, config files, markdown, and anything text-based.

How it works

When you ask Sparky to modify a file, it follows a safe workflow: read the current content, apply the changes, and show you a diff of what changed before saving.

Reading files

Sparky reads any text file in your project. It can read entire files or specific line ranges. For large files, it reads only the relevant sections to stay efficient.

Example prompt
"Show me the contents of src/main.ts"
"What's in the config file?"
"Read lines 50-100 of app.py"

Editing files

When you ask for a change, Sparky uses the edit tool to make precise, targeted replacements. It finds the exact text to change and replaces it — no need to rewrite the whole file.

Example prompt
"Change the port in config.ts from 3000 to 8080"
"Rename the function 'getData' to 'fetchData' in all files"
"Add error handling to the login function in auth.ts"

Creating files

When a file doesn't exist yet, Sparky creates it. It automatically creates any missing parent directories.

Example prompt
"Create a new React component called UserCard in src/components"
"Write a README.md for this project"

Viewing changes

Sparky shows you a diff — a side-by-side comparison of what changed. Added lines appear in green, removed lines in red. You can review every change before it's committed.

Limitations

  • Only works with text files — images, binaries, and other non-text files can't be edited.
  • Sparky won't overwrite your changes without showing you the diff first.
