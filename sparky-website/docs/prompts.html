Writing Prompts

How to talk to Sparky for the best results. Be specific, give context.

How to think about prompts

Talk to Sparky like a developer sitting next to you. The more specific, the better.

Good prompts

  • "The search page crashes on empty query — find handler in SearchPage.tsx and add a check"
  • "Find all calls to old pricing API and update them"
  • "Explain auth flow from login to session creation"
  • "Run tests, show failures, fix them"

Prompts that don't work well

  • "Fix it" — fix what? Which file?
  • "Make it better" — better how?
  • "Write a website" — too broad

Follow-up prompts

Sparky remembers the full conversation. Follow up naturally:

  • "That is close, but move the validation earlier"
  • "Also update the error message"
  • "Now do the same for other endpoints"
