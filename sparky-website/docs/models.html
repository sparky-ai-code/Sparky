Supported Models

Connect an AI provider and choose a model for your project. Sparky discovers the models available to your account; access can differ between an API key and a connected subscription.

Providers

Catalog checked September 14, 2026. The lists below are a selection, not a complete account-specific catalog. Check Settings in Sparky for your available models.

Official model catalogs: OpenAI, Anthropic, Google, and OpenCode Zen.

Click a provider to get your API key, then add it in Settings, Models. Sparky discovers available models automatically.

        OpenCode Zen

          OpenCode Zen routing

          Models whose IDs start with opencode/ use OpenCode Zen and the OPENCODE_API_KEY credential. They are not billed or labeled as OpenAI requests. OpenCode free-tier limits are enforced by OpenCode; when one is reached, select another model or try again later.

          Switching models

          Switch anytime in Settings, Models in the desktop app. Select the provider and model you want from the dropdown.
