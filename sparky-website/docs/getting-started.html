Quickstart

Install Sparky, connect your AI provider, and open your first project.

Step 1: Download Sparky

Grab the latest build from the download page. Choose the button for your computer:

  • Windows: open the installer and follow the prompts.
  • macOS: open the disk image and move Sparky to Applications. If macOS asks, right-click Sparky and choose Open.
  • Linux: download the AppImage, make it executable, and open it.

Step 2: Add your API key

Open Sparky, go to Settings, and paste your API key:

Step 3: Pick an AI model

Sparky works with whatever AI you already have. The app discovers available models automatically from your API key. Click a provider below to get started:

ProviderGet your API key
Anthropic (Claude)console.anthropic.com
OpenAI (GPT)platform.openai.com
Google (Gemini)aistudio.google.com
OpenCode Zenopencode.ai

Step 4: Start coding

Open Sparky, point it at your project folder, and tell it what you need in plain English. It reads your project, figures out the structure, and starts working.

Start without a project

Choose a project-free chat when you need a general answer or want to keep workspace files out of the provider context. The chat remains resumable; open a project later when you want file and terminal tools.

Keep Sparky up to date

Sparky checks for new versions in the background. If an update is available, you will see a notification in the app. Choose when to install it; your conversations and settings stay in place.
