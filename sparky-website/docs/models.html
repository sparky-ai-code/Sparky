Supported Models

Connect an AI provider and choose a model for your project. Sparky discovers the models available to your account; access can differ between an API key and a connected subscription.

Providers

Catalog checked October 3, 2026. Each provider has its own text-model listing below. Sparky also refreshes the full account-specific text catalog after you save a key in Settings, Models. Voice, audio, image, and video-only models are intentionally excluded.

Official model catalogs: OpenAI, Anthropic, Google, Fireworks, and Ollama Cloud.

Click a provider to get your API key, then add it in Settings, Models. For OpenAI, Sparky uses the official OpenAI SDK with your API key. You can also connect a ChatGPT account there to use eligible ChatGPT plan usage without an API key. Sparky discovers available models automatically, including the latest supported OpenAI and Anthropic models; the available catalog depends on your account and connection.

            ChatGPT account sign-in

            To use eligible ChatGPT plan usage, go to Settings, Models and choose Use your ChatGPT plan in the OpenAI provider settings. Sign in with your ChatGPT account in the browser and approve access. This is separate from an OpenAI API key; eligible Responses API usage is billed through your ChatGPT plan and subject to its limits. You can disconnect the plan from the same settings page.

            If sign-in fails or your plan is not connected, try again from the OpenAI provider controls in Settings, Models. For API-key setup, see Quickstart.

            Switching models

            Switch anytime in Settings, Models in the desktop app. Select the provider and model you want from the dropdown.
