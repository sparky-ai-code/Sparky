Troubleshooting

Common issues and how to fix them.

API key not set

Set the matching environment variable or paste the key in Settings, Models.

OpenCode free usage limit

If an OpenCode Zen model reports FreeUsageLimitError, the quota comes from OpenCode Zen rather than OpenAI. Confirm the OpenCode key is configured, then choose another model or wait for the upstream limit to reset.

Project-free chat says the runtime is outdated

Project-free chats require a Sparky runtime that supports --no-workspace-context. Rebuild or update the desktop binary, then retry the chat.

Sparky seems slow or hangs

Waiting for AI response or long command. Press Ctrl+C to interrupt. Try a different model if responses are consistently slow.

Sparky made the wrong edit

Tell it to undo and try again: "That is not right — undo and try a different approach." Sparky will revert and retry.

Command timed out

Split long tasks into smaller steps, or run long processes separately in another terminal.

Sparky stopped before finishing

Each prompt gets 40 rounds. Just run another prompt to continue — the session remembers everything.
