Pull Requests

Review GitHub pull requests without leaving Sparky. Connect your GitHub account, choose a repository, browse pull requests, and inspect the code changes directly inside the app.

Connect GitHub

The first time you open Pull Requests, Sparky will ask you to connect your GitHub account.

  1. Open Pull Requests from the Sparky sidebar.
  2. Click Connect GitHub.
  3. Your browser will open GitHub.
  4. Sign in to GitHub if needed and approve the connection.
  5. Return to Sparky.

Once connected, Sparky will load the repositories your GitHub account can access.

You normally only need to do this once.

Choose a repository

Use the repository selector at the top of the Pull Requests page to switch between repositories.

Sparky can show repositories from your GitHub account, including private repositories you have permission to access.

If the project currently open in Sparky is connected to a GitHub repository, Sparky will try to make that repository easy to find.

Browse pull requests

The left side of the Pull Requests page contains the pull request list.

Use:

  • All to view pull requests in the selected repository.
  • Authored to show pull requests created by you.
  • Search to find a pull request by its title, number, author, or branch.
  • Refresh to immediately check GitHub for changes.

Each pull request shows its number, author, branches, current state, and when it was last updated.

View a pull request

Select a pull request to open it inside Sparky.

The Summary view shows useful information such as:

  • Pull request title and description
  • Author
  • Source and target branches
  • Review status
  • Requested reviewers
  • Comments
  • Checks
  • Changed files
  • Additions and deletions
  • Labels
  • Current pull request status

This gives you the important context before you start reviewing the code.

Review code changes

Switch from Summary to Code to inspect the pull request diff.

Sparky shows:

  • Changed files
  • Added lines
  • Removed lines
  • The actual code changes contained in the pull request

You can use this view to understand what changed before continuing your work or asking Sparky to help review it.

Open the pull request on GitHub

Use Open in GitHub whenever you want to view the original pull request in your browser.

This is useful when you need GitHub features that are not currently exposed inside Sparky.

Working with Sparky

Because the pull request is available inside your workspace, you can use Sparky while reviewing it.

For example, you can ask:

Example prompts
"Explain what this pull request changes."
"Look for possible bugs in this PR."
"Review these changes for security problems."
"Explain why this file was changed."
"Compare this implementation with the existing codebase."

The more specific your request is, the more focused the review can be.

If your GitHub connection stops working

If Sparky can no longer access GitHub, the Pull Requests page will ask you to connect again.

Click Connect GitHub and complete the browser authorization.

If a repository does not appear, confirm that the GitHub account you connected has access to it. Organization repositories may also require approval or organization-specific access.
