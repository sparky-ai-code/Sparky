# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People who delegate software and knowledge work to Sparky agents across local, remote, and hosted environments.

## Product Purpose

Sparky helps users delegate work to AI agents while keeping projects, tools, context, and consequential actions under their control.

## Positioning

Sparky combines a persistent project-aware agent workspace with explicit access to tools, skills, previews, and human approval in one desktop-first experience.

## Operating Context

Users work across multiple projects and threads. They can extend an agent with provider skills and MCP servers while keeping access and consequential actions under their control.

## Capabilities and Constraints

- Provider skills and MCP servers can be invoked from chat.
- User approval remains explicit for consequential agent actions.
- The app supports light and dark themes, desktop window chrome, and responsive web layouts.

## Brand Commitments

Preserve Sparky's name, logo, blue accent, application tokens, component language, DM Sans typography, light and dark themes, and desktop-app behavior.

## Evidence on Hand

The repository contains the production app shell, chat composer, provider skill discovery, MCP execution support, Sparky logo assets, and established UI components. No verified third-party partnership, OAuth credential, or marketplace backend claim is available.

## Product Principles

- Make powerful tools and skills understandable before they are enabled.
- Keep the user in control of access, credentials, and agent actions.
- Turn setup into an editable conversation instead of a dead-end form.
- Prefer honest operational state over implied connectivity.
