Quickstart

A conversation with your codebase

Open a project and describe what you need. Sparky can read and edit files, run terminal commands, and help you review the changes, with your conversation beside the work.

  1. Bring your project and your AI

    Choose a project folder and connect a provider in Settings. Use the models guide to get connected.

  2. Give it a clear task

    Describe the result you want, the constraints to keep, and how to check the work.

  3. Review what changed

    Inspect the files, terminal output, and diff before deciding what to keep.

An example first task
Find where this app handles sign-in. Explain how it works and which files are involved. Don't change anything yet.

Keep the work in view

The sidebar gives you access to the project alongside the active conversation.

FilesBrowse the project tree and read the files involved.
TerminalRun commands and inspect tests or build output.
DiffRead changes before you commit.
BrowserOpen a local app or URL to inspect the result.

Continue the conversation

Sessions keep related work together. For questions that don't need workspace files or tools, start a project-free chat.

Use Memory for approved preferences and project conventions you want to carry forward. Keep secrets and credentials out of saved memory.

Connect your tools

Manage supported integrations from the Plugins panel. Connect the services you need, review their requested permissions, and disconnect them there when you're done.

Sparky shows the integration name in its activity entries so you can see which service is being used.

Ready to begin?

Follow the quickstart to install Sparky and open your first project. For release updates, see the changelog.
