Sessions

How sessions work

Every conversation with Sparky is saved automatically. Full history is always there.

Resuming a session

Sessions are in the sidebar of the desktop app. Click any one to continue where you left off.

Conversation continuity

Sparky stores the provider session binding and resume cursor with the thread. Follow-up prompts and server restarts continue the same provider conversation instead of silently starting over. If the saved session is unavailable, Sparky reports the problem rather than losing context.

Turn limits

Each prompt gets up to 40 rounds of tool calls. When reached, Sparky summarizes and you can continue with another prompt.
