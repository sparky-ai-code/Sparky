AI providers & models

Connect a provider and choose a model for your project. Sparky discovers the models available to your account; access can differ between an API key and a connected subscription.

Providers and live catalogs

Sparky supports OpenAI, Anthropic, Google Gemini, Fireworks, Ollama Cloud, Cerebras, and Groq. Provider model lists change over time and vary by account. The current catalog for your connections is shown in the desktop app under Settings, Models; this guide intentionally does not publish a fixed model list.

Provider catalogs: OpenAI, Anthropic, Google, Fireworks, Ollama Cloud, Cerebras, and Groq.

Click a provider below to get an API key, then add it in Settings, Models. For OpenAI, Sparky uses the official OpenAI SDK with your API key. You can also sign in with ChatGPT to use eligible subscription models without an API key.

After you connect a provider in Settings, Models, choose it there to view the live model catalog available to your account. Model names and availability can change without a Sparky release.

ChatGPT account sign-in

In Settings, Models, select Login with ChatGPT. Sparky opens a verification page and displays a device code; enter the code to authorize the account, then keep Sparky open while it finishes connecting. Your available ChatGPT models will then appear in Sparky, and you can disconnect from the same settings page.

If device-code sign-in is unavailable, enable it under ChatGPT Settings, Security and login (work accounts may require an administrator to allow it), or choose Try browser login if Sparky offers that fallback. For API-key setup, see Quickstart.

Switching models

Switch anytime in Settings, Models in the desktop app. Select the provider and model you want from the dropdown.
