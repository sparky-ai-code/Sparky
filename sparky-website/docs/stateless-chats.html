Stateless Chats

Ask questions without sending a project workspace as context.

What stateless means

A stateless chat, also called a project-free chat, runs without a project directory. Sparky does not read your files, extensions, MCP tools, or workspace settings until you open a project.

Stateless describes workspace context, not conversation continuity. The chat and provider session remain resumable across follow-ups and restarts.

When to use one

  • Ask a general question without exposing project files.
  • Draft an idea before choosing a workspace.
  • Keep personal or general conversations separate from project threads.
  • Use a clean conversation when workspace context would be distracting.

Start a stateless chat

  1. Create a new chat without selecting a project.
  2. Choose your provider and model as usual.
  3. Send the prompt. Sparky runs without project tools or workspace context.
  4. Open a project later when you need files, terminal commands, or project-scoped Memory.

Stateless chats and Memory

Stateless chats can still use the separate project-free Memory store when relevant. See Memory for how to control what Sparky remembers.
