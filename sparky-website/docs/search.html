Search

Find functions, variables, or any text pattern across your entire codebase.

How it works

Sparky has two search modes: content search (grep) finds text inside files, and file search (find) locates files by name.

Content search (grep)

Search for any text pattern inside your files. Uses regex for powerful matching.

Example prompts
"Find all places that call the old API"
"Search for handleLogin in all TypeScript files"
"Where do we define DATABASE_URL?"

File search (find)

Locate files by name, extension, or path pattern.

Example prompts
"Find all .py files in src"
"Where is the package.json?"
"List all test files"

Tips

  • Prefix with language name for better results
  • Use regex for complex searches
  • Combine with read: "Find the auth middleware and show me"
